# Nanotube dynamics

Tools for tracking fluorescent DNA nanotubes in microscopy images and analyzing tube motion and the ITO light response.

| Folder | Purpose |
| --- | --- |
| [tube_tracker/](tube_tracker/README.md) | Tube tracking software and graphical interface. |
| [tracking_analysis/](tracking_analysis/README.md) | Analysis of tube tracking data. |
| [ito_light_response/](ito_light_response/README.md) | Analysis of the ITO light response. |
| [legacy_scripts/](legacy_scripts/README.md) | Older exploratory analysis and diagnostic scripts. |
| [tests/](tests/README.md) | Interactive tracking tests and development scripts. |

`run_tracking_interface.py` launches the tube tracking interface.

[requirements.txt](requirements.txt) lists the direct dependencies used by the current analysis environment.

Experimental data, generated plots, handoff documents, and the mathematical writeup are kept local and excluded from Git.
